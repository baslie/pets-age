# Техническое задание: TrueDogAge.com

## 1. Общее описание проекта

### 1.1 Концепция

**TrueDogAge.com** — одностраничный веб-сайт для расчёта «человеческого» возраста собаки на основе научной формулы, разработанной учёными Калифорнийского университета в Сан-Диего.

В отличие от популярного упрощённого правила «1 собачий год = 7 человеческих», формула учитывает эпигенетические часы и паттерны метилирования ДНК.

### 1.2 Научная основа

Исследователи выяснили, что собаки стареют значительно быстрее в первые годы жизни, а затем процесс замедляется. К семи годам скорость старения у собак и людей выравнивается.

**Формула расчёта:**

```
Человеческий возраст = 16 × ln(возраст_собаки_в_годах) + 31
```

где `ln` — натуральный логарифм.

**Примеры расчётов:**

| Возраст собаки | Человеческий эквивалент |
|----------------|-------------------------|
| 8 недель (0.15 года) | ~1 год |
| 1 год | 31 год |
| 2 года | 42 года |
| 5 лет | 57 лет |
| 10 лет | 68 лет |
| 15 лет | 74 года |
| 20 лет | 79 лет |
| 25 лет | ~82 года |

**Дисклеймер:** Формула разработана на основе исследования лабрадоров-ретриверов. Применимость ко всем породам пока не подтверждена научно.

### 1.3 Цели проекта

1. Предоставить пользователям научно обоснованный инструмент для расчёта возраста собаки
2. Развенчать миф о правиле «1:7»
3. Создать виральный, удобный и визуально привлекательный продукт
4. Обеспечить международную аудиторию мультиязычной поддержкой

## 3. Функциональные требования

### 3.1 Калькулятор возраста

#### 3.1.1 Ввод через ползунки (основной сценарий)

- **Три отдельных ползунка:**
  - Годы: 0–25
  - Месяцы: 0–11
  - Дни: 0–30
- «Примагничивание» (snap) к целым значениям
- Возможность тапнуть на текущее значение и ввести число вручную с клавиатуры
- Touch target минимум 44px для мобильных устройств
- Визуальная обратная связь при взаимодействии (hover, active states)

#### 3.1.2 Ввод через дату рождения (альтернативный сценарий)

- Отдельная кнопка «Ввести дату рождения»
- Нативный date picker браузера
- Автоматический расчёт возраста от текущей даты
- Синхронизация с ползунками (при вводе даты ползунки обновляются)

#### 3.1.3 Отображение результата

- Крупное число «человеческого» возраста с анимацией счётчика
- Иллюстрация собаки, соответствующая возрасту:
  - Щенок (0–1 год)
  - Молодая собака (1–3 года)
  - Взрослая собака (3–8 лет)
  - Пожилая собака (8+ лет)
- Плавная смена иллюстрации при изменении возрастной категории
- Результат обновляется в реальном времени при движении ползунков

#### 3.1.4 Диапазон возраста

- **Минимум:** 0 лет, 0 месяцев, 1 день
- **Максимум:** 25 лет

### 3.2 Информационный блок

- Краткое объяснение формулы простым языком
- Упоминание Калифорнийского университета Сан-Диего как источника исследования
- Дисклеймер о том, что формула основана на лабрадорах
- Ссылка на оригинальное исследование (Cell Systems journal)

### 3.3 Шеринг в социальные сети

Кнопки шеринга:
- Twitter/X
- Facebook
- WhatsApp
- Telegram
- Копирование ссылки

Предзаполненный текст с результатом на языке пользователя. Пример: «Моей собаке 5 лет — это как 57 человеческих! Узнай возраст своей собаки: truedogage.com»

## 4. Дизайн и UX

### 4.1 Стиль: Необрутализм (Neobrutalism)

- Жёсткие тени: `box-shadow: 4px 4px 0 #000`
- Чёткие границы: border 3px solid #000
- Яркие, насыщенные цвета
- Крупная типографика
- Плоские заливки без градиентов

### 4.2 Цветовая палитра

```
Основной фон:     #FEF3C7
Карточки:         #FFFFFF
Акцент 1 (CTA):   #3B82F6
Акцент 2 (результат): #F472B6
Акцент 3 (успех): #34D399
Акцент 4 (декор): #FBBF24
Текст:            #1F2937
Границы/тени:     #000000
```

### 4.3 Типографика

- **Шрифт:** Inter (Google Fonts)
- **Заголовки:** 700 weight
- **Основной текст:** 400 weight
- **Числа результата:** 64px, font-variant-numeric: tabular-nums

### 4.4 Иллюстрации

- 4 иллюстрации собак: щенок, молодая, взрослая, пожилая
- Стиль: плоский, с чёрным контуром 2px
- Формат: SVG
- Будут предоставлены отдельно

### 4.5 Анимации

Framer Motion:

1. **Счётчик результата** — плавное изменение числа, 300ms, ease-out
2. **Смена иллюстрации** — crossfade, 400ms
3. **Фоновые элементы** — лёгкая пульсация, бесконечный цикл
4. **Ползунки** — spring анимация при snap (stiffness: 300, damping: 20)
5. **Появление элементов** — fade-in при загрузке, 500ms

Требования:
- Отключение для `prefers-reduced-motion: reduce`

### 4.6 Адаптивность

- Mobile-first подход
- Брейкпоинты Tailwind: sm (640px), md (768px), lg (1024px)
- Мобильные: вертикальная компоновка, ползунки друг под другом
- Десктоп: горизонтальная компоновка где уместно

## 6. SEO и метаданные

### 6.1 Базовые требования

- Semantic HTML
- Meta title: уникальный для каждого языка, до 60 символов
- Meta description: уникальный для каждого языка, до 155 символов
- Canonical URL для каждой языковой версии
- hreflang теги для всех языков
